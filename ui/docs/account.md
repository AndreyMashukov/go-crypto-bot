#### Зачем нужен внутренний баланс?
Внутренний баланс необходим для оплаты сервиса, мы тратим значительные средства на разработку, поддержку и аренду серверов, а так же обслуживание всей инфраструктуры проекта для его стабильной и бесперебойной работы. **Мы не имеем доступа к вашим средствам на криптобиржах, бот торгует исключительно в пределах биржи продавая и покупая ту или иную криптовалюту.**

> [!NOTE]
> **Варианты оплаты сервиса:**
> * **Комиссия:** Списание с внутреннего баланса (бюджета) системы Autotrade.cloud комиссии в размере 25-50% от полученной прибыли после закрытия позиции (см. ниже таблицу комиссии)
> * **Подписка:** Покупка подписки стоимостью 890 USDT освобождает пользователя (трейдера) от оплаты комиссии

| Уровень | Месячный объем торгов         | Процент комиссии | Минимальная комиссия | 
|---------|-------------------------------|------------------|----------------------|
| 1       | 0.00 USDT - 5000.00 USDT      | 50.00%           | 1.00$                |  
| 2       | 5000.00 USDT - 25000.00 USDT  | 35.00%           | 1.00$                |  
| 3       | 25000.00 USDT - 50000.00 USDT | 30.00%           | 1.00$                |  
| 4       | > 50000.00 USDT               | 25.00%           | 1.00$                |

> [!warning]
> Объем торгов считается отдельно по кажому боту и процент комиссии для каждого бота вычисляется исходя из месячного объема торгов конкретного бота.

> [!warning]
> Комиссия не может быть меньше **минимальной комиссии**, минимальная комиссия **1.00$** (один доллар), учитывайте это при установке бюджета и процента минимальной прибыли.  

#### Настройка торгового бота
В личном кабинете после регистрации пользователь может создать и настроить ботов, на текущий момент существует 2 бота
* Бот для Binance
* Бот для ByBit

Для того чтобы настроить бота под нужную биржу, нажмите на кнопку `НАСТРОИТЬ`, откроется диалоговое окно в которое нужно будет ввести API ключ и API secret, эти ключи вы можете найти в вашем аккаунте на Binance или ByBit
