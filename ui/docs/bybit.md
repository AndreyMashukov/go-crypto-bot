# Настройка бота ByBit

> [!Note]
> **Готовы торговать?** Перейдите на [autotrade.cloud](https://autotrade.cloud)<br>
> **У вас еще нет аккаунта на бирже ByBit?** Создайте его на [bybit.com](https://www.bybit.com/invite?ref=LJ1PDP)

Читайте подробнее на сайте ByBit [Как создать свой API ключ на ByBit](https://www.bybit.com/ru-RU/help-center/article/How-to-create-your-API-key)
> [!NOTE]
> Для того чтобы бот запустился, у вас должен быть **UNIFIED** аккаунт, как перейти на **UNIFIED** аккаунт читайте в статьях ниже
> * [Единый торговый аккаунт Bybit обновлён](https://www.bybit.com/ru-RU/promo/events/unified-trading-account/)
> * [Введение в Единый торговый аккаунт (UTA) Bybit](https://www.bybit.com/ru-RU/help-center/article/Introduction-to-Bybit-Unified-Trading-Account)
> 
> **Как выяснилось на ByBit для торговых символов (криптовалют), лучше выставлять значения бюджета не менее 15 usdt, так как шаг цены может быть разным и по итогу вычисленное количество купленной монеты будет ниже эквивалента 10$ и такой лимитный ордер на бирже не сможет быть размещен**

Если у вас все еще не **UNIFIED** аккаунт, а обычный **SPOT**, то вам требуется "проапгрейдить" свой аккаунт до UNIFIED, сделать это можно в настройках SPOT-торговли

<img src="/img/bybit/3.jpeg" alt="Апгрейд аккаунта до UNIFIED на ByBit" width="100%" style="max-width: 800px;vertical-align: top;margin-bottom: 10px;"/>

> [!NOTE]
> После того как **UNIFIED** аккаунт готов и ключ API создан, убедитесь что вы привязали ключ к нашим IP-адресам, на которых запускаются боты, это важно для безопасности вашего аккаунта на бирже. В случае привязки к определенным IP-адресам, ключи будут работать только с этих адресов, что значительно повышает безопасность. Актуальные IP-адреса вы всегда можете найти в настройках бота (см ниже скриншот). **При этом не требуется устанавливать все права в ключах, достаточно только прав на SPOT-торговлю (Trade)**.

<img src="/img/bybit/1.jpeg" alt="Как создать API ключ на ByBit" width="100%" style="max-width: 700px;margin-bottom: 10px;"/>
