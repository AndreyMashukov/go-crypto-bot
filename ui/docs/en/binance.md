# Setting Up Binance Bot

> [!Note]
> **Ready to trade?** Go to [autotrade.cloud](https://autotrade.cloud)<br>
> **Don't have a Binance account yet?** Create one at [binance.com](https://www.binance.com/en/activity/referral-entry/CPA/together-v3?ref=CPA_00RR51I65L)

Learn more on the Binance website about [How to create API keys on Binance](https://www.binance.com/en/support/faq/how-to-create-api-keys-on-binance-360002502072)

> [!NOTE]
> Make sure you link the key to our IP addresses, which is where the bots are launched, as this is important for the security of your account on the exchange. If linked to specific IP addresses, the keys will only work from these addresses, significantly enhancing security. You can always find the current IP addresses in the bot settings (see screenshot below). **Note that it is not necessary to set all permissions in the keys, only SPOT trading (Trade) permissions are sufficient.**
