# Setting Up ByBit Bot

> [!Note]
> **Ready to trade?** Go to [autotrade.cloud](https://autotrade.cloud)<br>
> **Don't have a ByBit account yet?** Create one at [bybit.com](https://www.bybit.com/invite?ref=LJ1PDP)

Learn more on the ByBit website about [How to create your API key on ByBit](https://www.bybit.com/en-US/support/articles/360039749613)

> [!NOTE]
> To get the bot running, you must have a **UNIFIED** account. Read the following articles to learn how to upgrade to a **UNIFIED** account:
> * [Bybit Unified Trading Account Updated](https://www.bybit.com/en-US/promo/events/unified-trading-account/)
> * [Introduction to Bybit Unified Trading Account (UTA)](https://www.bybit.com/en-US/support/articles/360051159173)
>
> It has been noted that for ByBit trading symbols (cryptocurrencies), it is better to set the budget to no less than 15 USDT because the price step can vary and the calculated amount of cryptocurrency purchased might be lower than a $10 equivalent and such a limit order will not be placed on the exchange.

If you still have a regular **SPOT** account, you will need to upgrade it to a **UNIFIED** account, which can be done in the SPOT trading settings.

> [!NOTE]
> Once your **UNIFIED** account is ready and the API key is created, make sure you bind the key to our IP addresses where the bots are launched, which is crucial for the security of your account on the exchange. If linked to certain IP addresses, the keys will only work from those addresses, significantly enhancing security. You can always find the current IP addresses in the bot settings (see screenshot below). **It is not necessary to set all rights in the keys; only SPOT trading (Trade) rights are sufficient.**
